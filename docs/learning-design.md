# Learning design

Audience: interested adult beginners who want to interpret human behaviour using evidence. The gap is between attaching an intuitive label and explaining a case with accurate concepts, alternatives and limits. Delivery is a standalone, accessible, learner-paced GitHub Pages course, not an LMS or certification.

The established café visual identity uses Libre Baskerville headings, Arimo body text, pale blue backgrounds, navy text, teal interactions and restrained chapter accents. Reading and controls precede the supporting figure in the stacked layout. The primary learning path remains clear when research disclosures stay closed.

Each chapter has a first decision, three separate narrated explanations, a visible evidence check, a new written transfer case, unaided retrieval and low-stakes field practice. The final case integrates chapters. Page visits indicate navigation, not mastery. No learner pilot or independent academic review has been conducted.

## 1. An action can have several motives

Objective: Distinguish an observed action from a proposed motive and generate a testable alternative.

Initial decision: What should replace the low-motivation label?

Transfer: A volunteer attends when sessions fit caring responsibilities and misses sessions that conflict. What conclusion is proportionate?

Field application: Use a fictional early departure to write two motive hypotheses and a respectful question that would help distinguish them.

## 2. Needs and incentives interact

Objective: Explain how bodily regulation and environmental incentives can both influence action.

Initial decision: Which account fits the two observations best?

Transfer: A café changes its opening hours and visitors’ meal choices shift. What is the most careful conclusion?

Field application: Use a fictional choice to identify a bodily influence, a learned cue and an access condition without judging the person.

## 3. Value and expectation shape effort

Objective: Distinguish valuing an outcome from expecting that effort will achieve it.

Initial decision: What is the key distinction in Jo’s case?

Transfer: A learner values a task but doubts that the available strategy will help. Which support most directly tests the route?

Field application: For a harmless personal goal, separate value, expectancy, cost and one practical support. Test the route rather than your worth.

## 4. Autonomy is not doing everything alone

Objective: Distinguish autonomy, competence and relatedness from absence of structure or universal rewards rules.

Initial decision: What should the café add?

Transfer: A volunteer dislikes data entry but freely values its role in keeping the café accessible. Which description fits best?

Field application: Evaluate a fictional task using meaningful choice, workable guidance and respectful connection. Identify one improvement.

## 5. Goals need feedback and room to revise

Objective: Design a suitable process goal and evaluate a measurable outcome without optimizing a harmful proxy.

Initial decision: What is the problem with the repair target?

Transfer: New volunteers are learning an unfamiliar diagnostic procedure. Which plan best fits a new complex skill?

Field application: Choose a harmless personal learning goal. Define a process, a meaningful outcome and evidence that would make you revise the plan.

## 6. Approach and avoidance can coexist

Objective: Explain an ambivalent choice without treating avoidance as weakness or approach as universally better.

Initial decision: What best explains Jo’s mixed response?

Transfer: A volunteer wants to contribute but declines a particular public format. Which response is most appropriate?

Field application: Use a fictional ambivalent decision to name both outcomes and propose one respectful alternative route.

## 7. An emotion has several components

Objective: Distinguish subjective feeling, physiology, expression and appraisal without treating any one as a unique readout.

Initial decision: What does Sam’s smile establish most directly?

Transfer: A person’s pulse rises during a challenging social task. Which conclusion is best supported?

Field application: Use a fictional scene to describe expression, possible appraisal and a respectful question. Leave the actual feeling open.

## 8. Regulation is choosing a response to a context

Objective: Compare regulation strategies and select an appropriate option without claiming one strategy is always best.

Initial decision: Which account best fits Jo’s plan?

Transfer: A person feels distressed in a genuinely unsafe situation. What should come first?

Field application: For a fictional low-stakes disagreement, compare a situation change and a reinterpretation. State which facts would make each appropriate.

## 9. Feelings are also social information

Objective: Explain social emotions without inferring a universal meaning from one expression or norm.

Initial decision: What is the best response to different expressions of regret?

Transfer: A friend feels strongly moved by someone’s distress and assumes they know which help is wanted. What would improve the support?

Field application: Use a fictional apology scene to distinguish observed words, inferred emotion and a meaningful repair action.

## 10. A useful change needs more than enthusiasm

Objective: Evaluate a motivation or emotion intervention using meaningful outcomes, alternatives and limits.

Initial decision: What is missing from the workshop promise?

Transfer: Participants report improved mood after one session; there is no control group or follow-up. Which report is proportionate?

Field application: Write a balanced review of a fictional wellbeing workshop: useful idea, actual evidence, missing comparison and a bounded conclusion.
